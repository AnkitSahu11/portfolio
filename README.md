# Ankit Sahu — MERN Stack Developer Portfolio

A React + Vite portfolio with reusable components and separate page sections.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/App.jsx` — app layout and section composition
- `src/components/` — reusable UI components
- `src/sections/` — individual portfolio sections
- `src/data/portfolio.js` — profile, skills, projects, education and experience content
- `src/styles.css` — global styles
- `vite.config.js` — Vite React plugin and automatic JSX runtime

Only the two projects listed in the supplied resume are included: PixSort and URL Shortener.
